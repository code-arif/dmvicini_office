# 📬 DMVICINI Backend

Welcome to the **DMVICINI** project! This is the backend for a post-like social and event management platform, built with Laravel. It provides APIs and services for managing users, posts, events, and more.

## 🚀 Features
- User authentication & role management
- Post creation, editing, and deletion
- Community and social feed features
- Real-time chatting system
- Event management (manual & API integrated)
- Contact & FAQ modules
- Dynamic pages & settings management
- Email notifications (OTP, password reset, updates)

## 🛠️ Tech Stack
- **PHP** (Laravel Framework)
- **MySQL** (or compatible database)
- **Tailwind CSS** (for frontend assets)
- **Vite** (asset bundler)

## 📂 Project Structure
- `app/` - Core application code (models, controllers, services)
- `routes/` - API and web routes
- `resources/` - Views, CSS, JS assets
- `public/` - Public assets
- `database/` - Migrations, seeders, factories

## 🏁 Getting Started
1. Clone the repository
2. Run `composer install`
3. Copy `.env.example` to `.env` and configure your environment variables
4. Run `php artisan migrate --seed`
5. Start the server: `php artisan serve`
